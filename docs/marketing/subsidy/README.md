# IT導入補助金 申請資料ディレクトリ

本ディレクトリは、デジタル化・AI導入補助金2026 インボイス枠（インボイス対応類型）の
申請添付書類として使用する3点の資料の**公開Webページ（Next.js）と原稿の対応表**です。

Webページは `/subsidy/*` で誰でも閲覧でき、各ページ右上の「PDFとして保存 / 印刷」
ボタンから A4 印刷レイアウトで PDF として保存できます。

## PDFダウンロード方針

本プロジェクトでは、**ブラウザの印刷 → PDFとして保存機能**を使用してPDFを生成する
方式を採用しています。理由:

1. 追加の依存関係（Puppeteer / @react-pdf/renderer 等）なしで実装可能
2. 資料の内容を更新すれば即座にPDF出力にも反映される
3. 申請者・審査担当者が自分の環境で印刷設定（余白・向き）を調整できる

各資料ページは `@media print` CSS で最適化されており、印刷時にはヘッダー・ナビ・
「印刷ボタン」が非表示になり、A4 レイアウトに整形されます。

## 画像差し込み

申請書類には画面キャプチャの添付が求められます。
現時点ではプレースホルダー（点線枠）を配置しており、画像受領後に `<img>` に差し替えます。
必要なキャプチャは `docs/marketing/screenshots-needed.md` にまとめています。

## Pコード選択の方針

受発注Lシステムが該当する Pコード:

- **主 Pコード: 共P-02（決済・債権債務・資金回収）** — 発注・仕入管理、買掛・支払管理、
  受注・売上請求管理、売掛・回収管理 の各機能を保有
- 副 Pコード: 共P-03（供給・在庫・物流）— 納品管理ステータス遷移に対応
- 副 Pコード: 汎P-07（汎用・自動化・分析ツール）— 承認ワークフロー機能

詳細は `/subsidy/requirements` ページおよび `requirements.md` を参照してください。
