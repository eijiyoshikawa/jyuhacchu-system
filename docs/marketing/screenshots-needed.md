## 配置手順

1. 各スクリーンショットを、上表の「保存ファイル名」のまま
   `public/images/subsidy/` 配下に保存（コミット）。
2. `npm run dev` で `/subsidy/feature` と `/lp` を開いて表示確認。
3. 印刷プレビュー（Ctrl+P / ⌘+P）で A4 PDF 出力時に画像切れがないか確認。

ファイルが存在しない場合は自動的に点線プレースホルダーに戻り、ページはエラーなく
描画されます（`ScreenshotPlaceholder` の `src` 分岐処理）。

## 撮影条件（推奨）

- ブラウザ: Chrome 最新版
- ウィンドウ幅: 1280〜1440px
- ログイン: 管理者ユーザー（`admin@sample-trading.co.jp` / `password123`）
- デモデータ: `npx prisma db seed` 実行済み
- ファイル形式: PNG（可逆圧縮）、長辺 1920px 以内
- 切り抜き: OSメニューバー・URLバーは除外、サイドバー込み
